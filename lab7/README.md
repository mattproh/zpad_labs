Опис проєкту
Ця лабораторна робота демонструє обробку відеопотоку в реальному часі за допомогою OpenCV: використання візуальних фільтрів та нейромережі (ResNet-10) для детекції облич. Для уникнення блокування UI (графічного інтерфейсу) важкими обчисленнями, інференс нейромережі винесено в окремий фоновий потік.

Керування
F - Детекція облич (Face Detect)
N - Нормальний режим (Normal)
I - Інверсія кольорів (Invert)
B - Розмиття (Gaussian Blur)
C - Виділення контурів (Canny Edge)
Q або ESC - Вихід з програми
ЛКМ (затиснути) - Малювання зеленого прямокутника
Trackbar - Зміна рівня яскравості

Інструкція зі збірки
Проєкт розрахований на роботу в середовищі Linux (Ubuntu).
1. chmod +x *.sh — надання прав на виконання.
2. ./preinstall.sh — завантаження залежностей та ваг нейромережі.
3. ./build.sh — компіляція проєкту (CMake + Make).
4. ./run.sh — запуск програми.

Архітектура проєкту
Проєкт розділено на незалежні класи:

CameraProvider: Захоплення кадрів з веб-камери. Використовує примусовий драйвер cv::CAP_V4L2 для стабільної роботи без буферизації у віртуальних машинах Linux.

Display: Робота з вікнами (HighGUI), створення Trackbar-ів та обробка callback-подій миші.

KeyProcessor: Керування станами (State Machine). Приймає коди клавіш і повертає безпечний enum class Mode.

FrameProcessor: Застосування матричних трансформацій до кадру (Blur, Canny тощо). Також відповідає за підрахунок і відображення FPS на основі cv::getTickCount().

FaceDetector: Асинхронна робота з DNN (Deep Neural Networks).
Багатопотоковість: Використовує std::thread для фонового пошуку облич. Для безпечного обміну кадрами та координатами між потоками використовується std::mutex із std::lock_guard, що запобігає збоям (race conditions).
