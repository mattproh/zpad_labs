# Лаб 6

Програма для захоплення та обробки відеопотоку з веб-камери в реальному часі.

## Вимоги до системи
* **ОС:** Linux (рекомендовано Ubuntu / Debian)
* **Залізо:** Наявність підключеної веб-камери (у віртуальній машині необхідно прокинути пристрій `/dev/video0`).
* **Залежності:** `gcc`, `g++`, `cmake`, `libopencv-dev`.

## Інструкція зі збірки та запуску

Щоб зібрати та запустити програму на чистій системі, виконайте наступні команди з кореневої директорії проєкту:

1. Встановіть необхідні бібліотеки:
   `./preinstall.sh`
   
2. Скомпілюйте програму:
   `./build.sh`
   
3. Запустіть застосунок:
   `./run.sh`

## Керування (Інтерактив)
* **Клавіатура (Режими обробки):**
  * `N` - Нормальний режим (без фільтрів)
  * `I` - Інверсія кольорів
  * `B` - Розмиття (Gaussian Blur)
  * `C` - Виділення контурів (Canny Edge Detection)
  * `Q` або `ESC` - Вихід з програми
* **Миша:** Затисніть ліву кнопку миші та потягніть, щоб намалювати зелений прямокутник на кадрі.
* **Слайдер (Trackbar):** Змінює яскравість зображення (за замовчуванням стоїть на 50, що відповідає оригінальній яскравості).
