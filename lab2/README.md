Лабораторна робота 2: Наука про дані: підготовчий етап

Опис завдання
Робота складається з двох частин:
1. Зчитування та очищення даних VHI індексу (NOAA) по областях України.
2. Аналіз та фільтрація датасету Individual Household Electric Power Consumption.

Інструкція із запуску
Всі залежності знаходяться у файлі requirements.txt. Для запуску необхідно активувати віртуальне середовище та відкрити файли `.ipynb` у Jupyter Notebook.
