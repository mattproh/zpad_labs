Лабораторна робота №4: Візуалізація даних 2

Інструкція користувача:
Amplitude, Frequency (ω), Phase (φ) — слайдери для зміни параметрів основної чистої гармоніки.
Noise Mean, Noise Covariance — слайдери для налаштування характеристик накладеного шуму (зміщення та дисперсія).
Cutoff Freq — налаштування частоти зрізу фільтра низьких частот Баттерворта. Чим менше значення, тим сильніше фільтр згладжує зашумлений сигнал.
Show Noise — чекбокс для увімкнення/вимкнення відображення помаранчевого зашумленого сигналу.
Reset — кнопка для повернення всіх повзунків до початкового стану.

Для запуску програми використовуйте команду: `python lab4_zpad.py`
